# To-Do List API

A REST API for a to-do list application, built with Java and Spring Boot.

This project is currently in the early stages of development and aims to explore backend development, RESTful API design, and data persistence using the Java ecosystem.

## Project Status

🚧 Work in Progress

The API is being developed incrementally, with new features and improvements added as the project evolves.

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Maven
- H2 Database
- PostgreSQL

## Current Progress

- Initial Spring Boot project setup.
- Initial user retrieval endpoint (`findAll`).

## Planned Features

- Expand user management endpoints.
- Implement task management functionality.
- Add data validation and error handling.
- Improve automated test coverage.

## About the Project

This project is an opportunity to practice backend development with Java and Spring Boot while building a RESTful API.

As development progresses, the repository will be updated with new features, improvements, and additional documentation.
